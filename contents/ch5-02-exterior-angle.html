알게 된 것

삼각형을 아무리 바꿔도 한 외각의 크기는 그와 이웃하지 않은 두 내각의 크기의 합과 같아요. 또 한 꼭짓점에서 내각 + 외각 = 180° 예요. (교과서 181쪽)

활동 2 평행선으로 설명하기

점 C 를 지나 변 AB 에 평행한 반직선 CE 를 그으면, 4단원에서 배운 엇각·동위각 으로 설명할 수 있어요. (교과서 182쪽)

  1. 삼각형 ABC 와 ∠C 의 외각 ∠ACD
  2. 점 C 를 지나 AB 에 평행한 반직선 CE 긋기
  3. 엇각 : ∠ACE = ∠A
  4. 동위각 : ∠ECD = ∠B
  5. ∠ACD = ∠ACE + ∠ECD = ∠A + ∠B
